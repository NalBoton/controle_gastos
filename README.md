# Controle de Gastos

Um programa simples desenvolvido em **Python** para praticar conceitos básicos de **Programação Orientada a Objetos (POO)**.

O programa permite informar um valor inicial, registrar despesas e acompanhar quanto dinheiro ainda está disponível após os descontos.

## 📌 Sobre o projeto

O **Controle de Gastos** foi criado como um projeto de estudo para praticar conceitos importantes do Python, como:

* Classes e objetos
* Métodos
* Atributos
* Entrada de dados
* Estruturas condicionais
* Estruturas de repetição
* Dicionários
* Funções

O programa funciona através do terminal e permite que o usuário acompanhe seu saldo enquanto registra suas despesas.

## ⚙️ Funcionalidades

Atualmente, o programa possui as seguintes opções:

* 👤 Informar o nome do usuário
* 💵 Informar o salário/valor inicial
* ➖ Aplicar uma despesa de **R$ 25**
* ➖ Aplicar uma despesa de **R$ 50**
* ➖ Aplicar uma despesa de **R$ 100**
* ✏️ Informar uma despesa personalizada
* 📊 Consultar o saldo atual
* ⏳ Consultar o histórico das despesas
* 📖 Visualizar as instruções do programa
* 🚪 Encerrar o programa mostrando o saldo final

## ▶️ Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/NalBoton/controle_gastos.git
```

### 2. Entre na pasta do projeto

```bash
cd controle_gastos
```

### 3. Execute o programa

```bash
python diagnostico.py
```
